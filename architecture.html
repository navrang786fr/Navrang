03 Core Subsystem Details

Modular Design
📱

Customer PWA Shell (`order.html`)

Flagship digital menu loaded instantly via QR code scan on dining tables.
  • Bilingual Engine: Instant toggle between English and Telugu (`తెలుగు`).
  • Smart Search & Filters: Instant search by name, Telugu script, and ingredients.
  • Biryani Catcher Game: 60 FPS HTML5 Canvas mini-game while waiting.
  • Split Bill Utility: Guest bill splitting with clipboard copy and screenshot download.
  • Social Channels: YouTube Channel & Instagram 5% OFF banner integration.
🖥️

On-Premise POS (`server.py`)

Local multi-threaded Python server coordinating table orders and cashier billing over LAN.
  • Zero Cloud Dependence: Restaurant continues billing during internet outages.
  • Thread-Safe Storage: Atomic file swaps on `pos-orders.json` prevent race conditions.
  • Waiter Handheld Mode: Tables, item add/remove, kitchen ticket dispatch.
  • Counter POS Mode: Bill settlement, tender selection (Cash/UPI/Card), receipt printing.
  • Daily Collections: Automatic end-of-day revenue audit and settlement reports.
⚡

Cloud Serverless (`ratings-api`)

Node.js serverless microservices hosted on Vercel handling reviews, tracking, and catalog CRUD.
  • Git-as-a-Database: Public/Private GitHub repos as relational state storage.
  • Optimistic Concurrency: SHA-validated PUT commits with retry loops on 409 conflicts.
  • Sliding-Window Throttling: IP rate limiting to prevent spam and review manipulation.
  • Automated Backups: Daily Vercel Cron worker snapshots 7-day activity logs.
  • Stateless JWT Auth: HMAC-SHA256 tokens for admin & management portals.

07 Reliability & Security Pillars

Enterprise Grade

1. Survives Total Internet Outages

The floor POS system runs on an on-premise local server (`server.py`). Even if the restaurant's broadband connection is severed, waiters can still place table orders, the kitchen receives KOTs, and the counter can print receipts and log cash payments seamlessly over the local Wi-Fi router.

2. Zero Plaintext Credential Exposure

Administrative tokens, JWT secrets, and fine-grained GitHub PATs are injected securely as serverless runtime environment variables (`JWT_SECRET`, `ADMIN_GITHUB_TOKEN`). Public repositories contain zero database passwords or private API keys.

3. Customer Privacy by Design (SAIF Framework)

Sensitive diagnostic data like customer IP addresses, device user agents, and geolocation are segregated into the private `admin-db` repository. Public assets served to browsers (`ratings.json`, `menu-data.js`, `game-stats.json`) strictly contain sanitized business data.

4. Zero CDN Stale Cache Headaches

Whenever an administrator changes a dish price or adds an item, the script loader appends a fresh timestamp hash (`menu-data.js?v=Date.now()`), completely bypassing aggressive mobile browser caches without requiring manual cache clearing by dining customers.
